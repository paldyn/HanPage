HanPage Desktop 0.8.9

- 업데이트 팝업을 화면 가운데에 배치하고, 앱 테마와 어울리는 별도 색상으로 구분했습니다.
- 최신 버전 안내에서는 `닫기`와 `다시 확인`을 제공합니다.
- 백그라운드 업데이트는 하단 상태 버튼에 표시합니다. 상태 버튼, `파일 > 업데이트 확인`, macOS `HanPage > 업데이트 확인`에서 상세 안내를 다시 열 수 있습니다.
- 제품 정보의 회사 표기를 `PALDYN`으로 통일했습니다.

다운로드 진행률·용량, 파일 확인·적용 중 표시, 저장 확인과 적용 중 입력 보호, 실패 후 재시도는 유지합니다. 새 화면은 0.8.9 설치 후 적용됩니다.

macOS Apple Silicon은 DMG, Windows x64는 설치 EXE를 사용할 수 있습니다. 기존 앱에서는 자동 업데이트 또는 업데이트 확인 메뉴를 이용할 수 있습니다.

양 플랫폼 빌드와 실제 배포 자산, 자동 업데이트 서명, macOS 코드 서명·공증을 확인했습니다. [변경 PR](https://github.com/paldyn/HanPage/pull/116).
