# Desktop 0.8.6 초안 릴리스 노트 (보존본)

릴리스 ID 401464978(`hanpage-desktop-v0.8.6`), 2026-10-02 생성, 자산 0개. 이 버전은 공개되지 않았고 초안을 지우기 전에 원문을 여기 옮겼다
(2026-11-04, [#172](https://github.com/paldyn/HanPage/issues/172)). git 태그는 이 번호를 이미 썼다는 기록이라 남긴다.

---

## 변경 내용

- HWP/HWPX 엔진과 편집기를 upstream 0.8.6으로 통합했습니다.
- 앱과 Dock, Windows 실행 파일·설치 프로그램에 새 한글 심볼 로고를 적용했습니다.
- 네이티브 파일 열기·저장, 연속 파일 열기 큐, 최근 문서·제목 처리를 보존했습니다.
- 폰트 로딩 시간 제한과 남은 폰트의 백그라운드 로딩을 유지했습니다.
- 자동 업데이트는 준비가 끝나면 설치 안내를 표시합니다. macOS는 재시작하고 Windows는 설치 프로그램을 실행합니다.

## 설치 파일

- macOS Apple Silicon: `HanPage_0.8.6_aarch64.dmg`
- Windows x64: `HanPage_0.8.6_x64-setup.exe`

기존 앱에서는 앱을 실행하거나 메뉴의 업데이트 확인을 이용해 설치할 수 있습니다. 설치 후 앱을 다시 열면 새 로고와 기능이 반영됩니다.
