HanPage Desktop 0.8.12

**문서마다 창 하나**

- 다른 한글 파일을 열면 새 창에서 엽니다. 지금 창이 아무것도 쓰지 않은 빈 문서면 그 창에서 엽니다. Finder·탐색기 더블클릭, 파일 > 열기, macOS의 파일 > 최근 문서로 이미 열려 있는 파일을 열면 그 창을 앞으로 가져옵니다. 창에 끌어다 놓은 파일은 빈 창이 아니면 새 창에서 열리며, 이미 열려 있는 파일이어도 새 창으로 열립니다. 끌어다 놓아 연 문서는 파일 경로를 알 수 없어서, 같은 파일을 나중에 Finder·탐색기나 파일 > 열기로 열면 새 창이 생깁니다. 새 창은 앞 창 옆에 비스듬히 뜹니다.
- 창을 닫거나 macOS에서 Cmd+Q로 끝낼 때 저장하지 않은 문서가 있으면 저장할지 묻습니다.
- 업데이트를 적용하기 전에 다른 창에 저장하지 않은 문서가 있으면 그 창을 보여 주고 멈춥니다. 업데이트 준비 알림은 창이 여러 개여도 한 번만 뜹니다. 이 두 가지는 0.8.12를 설치한 다음 업데이트부터 적용됩니다.
- 창 제목에 문서 이름이 표시됩니다.

**AI 도우미(새 기능)**

- 도구 메뉴에 AI 도우미를 더했습니다. AI 설정에 본인의 Anthropic(Claude) API 키를 등록하고 문서 내용 전송에 동의해야 쓸 수 있으며, 질문하면 현재 문서 내용 일부가 Anthropic으로 전송되고 요금은 그 키 계정에 청구됩니다. AI가 제안한 문서 변경을 확인 없이 바로 적용하는 옵션이 있습니다(Ctrl+Z로 되돌릴 수 있음).

**그 밖의 변경**

- 문서 엔진과 편집기를 rhwp 0.8.7로 올렸습니다.
- 파일 > 열기에서 PDF(가져오기)와 HML 문서도 고를 수 있습니다.
- HWPX로 저장할 때 macOS에서 확장자가 `.hwp`로 바뀌던 문제를 고쳤습니다. PDF 파일 위에는 저장하지 않습니다.
- PDF에서 가져온 문서는 처음 고른 저장 형식을 기억해, 저장할 때마다 다시 묻지 않습니다.
- 대화상자나 AI 도우미 입력창에 커서가 있을 때 macOS 편집 메뉴(실행 취소·잘라내기·복사·붙여넣기 등)가 문서를 바꾸지 않습니다.
- 업데이트를 적용할 때는 그 창의 AI 도우미를 먼저 멈춥니다.

**Windows 설치 안내** — 설치 파일은 코드 서명 없이 배포합니다. 브라우저가 "일반적으로 다운로드되지 않는 파일"로 표시하면 `⋯` 메뉴에서 `유지`를 선택하세요. 처음 실행할 때 "Windows의 PC 보호" 화면이 뜨면 `추가 정보 → 실행`을 누르세요. 공식 배포처는 이 GitHub Releases와 hanpage.paldyn.com의 다운로드 버튼뿐입니다.

macOS Apple Silicon은 DMG, Windows x64는 설치 EXE를 사용할 수 있습니다. 기존 앱에서는 자동 업데이트 또는 업데이트 확인 메뉴를 이용할 수 있습니다.

양 플랫폼 빌드와 실제 배포 자산, 자동 업데이트 서명, macOS 코드 서명·공증을 확인했습니다. 변경 PR: [#155](https://github.com/paldyn/HanPage/pull/155), [#157](https://github.com/paldyn/HanPage/pull/157), [#168](https://github.com/paldyn/HanPage/pull/168), [#169](https://github.com/paldyn/HanPage/pull/169).
