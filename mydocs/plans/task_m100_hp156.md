# Task #156 (M100) — Desktop 문서마다 창 하나 수행계획서

- **이슈**: [paldyn/HanPage#156](https://github.com/paldyn/HanPage/issues/156)
- **브랜치**: `claude/desktop-multi-window` (`origin/devel` `2b23c21c7` 분기)
- **작업지시자 요청(2026-10-28)**: "그리고 처음에 한글파일열면 한페이지로 열리잖아? 그리고 내가 또다른 한글파일 열면
  또다른 한페이지창으로 열렸으면하는데. 앱버전."

## 1. 현재 동작

| 경로 | 동작(base `2b23c21c7`) |
|---|---|
| Finder·탐색기 더블클릭, 연결 프로그램, macOS 최근 문서 | 앱 전체에 하나인 대기 문서 큐(`PENDING_DOCUMENTS`)에 넣고 모든 창에 `documents-ready` 를 보낸다. 창은 `main` 하나라 그 창의 문서를 바꾼다(미저장이면 저장 확인) |
| 파일 > 열기 | 네이티브 열기 대화상자의 바이트를 부른 창에서 연다 |
| 끌어다 놓기 | 놓은 창의 문서를 바꾼다 |
| macOS 메뉴 | `app.emit` 으로 모든 창에 보낸다 |
| 창 닫기·Cmd+Q | 묻지 않고 끝낸다(기본 `quit` 항목) |

창을 그냥 더 만들기만 하면 큐를 먼저 비운 창이 다른 창 몫까지 가져가 편집 중인 문서를 덮고, 메뉴의 저장·붙이기가
모든 창에서 실행된다. 창이 여럿이 되면 창 하나를 닫아도 앱이 남으므로 저장하지 않은 문서를 묻지 않고 닫는 것도
문제가 된다.

## 2. 규칙

1. 문서는 지금 창(가장 최근에 포커스한 창)이 **손대지 않은 빈 창**일 때만 그 창에서 연다. 아니면 새 창 `doc-N` 을
   만든다. 이미 어떤 창에 열린 파일이면 그 창을 앞으로 가져온다.
2. 1을 Finder·탐색기·연결 프로그램, macOS 최근 문서, 파일 > 열기, 끌어다 놓기에 똑같이 적용한다.
3. 파일 > 새 문서, AI 도우미, 문서 비교, 자동 저장 복구는 지금 창에서 바꾼다(기존 동작).
4. 손대지 않은 빈 창: 시작할 때의 빈 문서나 새 문서 그대로인 창. 문서를 여는 중이거나 한 번 입력·저장한 창은 아니다.
   문서를 열지 못하면(암호 취소·읽기 실패) 다시 빈 창이 된다.

## 3. 설계

- **Rust `src-tauri/src/windows.rs`(순수 상태, 단위 테스트)**: 창 목록과 최근 순서, 창별 대기 문서, 문서를 받을 창 결정
  (`Focus`·`Into`·`New`), 배정한 파일의 예약(대기 중일 때만 같은 파일 판단에 사용), 시작 단계(`Booting`→`Startup`→
  `Ready`), 닫기 판단(묻기·대기·응답 없는 창의 네이티브 확인), Cmd+Q 종료 진행.
- **`lib.rs`**: 파일 연결·최근 문서·열기 대화상자·넘겨받은 문서를 같은 `deliver` 로 보낸다. 새 창은 첫 창 설정을
  복제해 별도 스레드에서 만들고(Windows 교착 회피) 실제로 만들어졌는지 확인한다. 메뉴는 가장 최근 창에만, 닫기
  요청은 저장하지 않은 창이면 막고 웹뷰에 묻는다. 업데이트 적용 전 다른 창의 저장하지 않은 문서를 확인한다.
- **웹뷰 `desktop-bridge.ts`·`main.ts`**: 창 전용 이벤트(`listen(…, {target})`)만 받고, 시작 흐름이 끝난 뒤 창 상태
  (빈 창·변경 있음·열린 파일)를 보고한다. 받을 수 없는 문서(끌어다 놓기, 늦게 도착한 문서)는 새 창으로 넘긴다.
  닫기 요청에 기존 저장 확인으로 답한다. 창 제목을 문서 이름으로 맞춘다.
- **업데이트**: 작은 준비 알림은 실행마다 앱 전체에서 버전당 한 번. 다른 창에 저장하지 않은 문서가 있으면 이 창의
  저장 확인·AI 도우미 정리 전에 멈추고 그 창을 보여 준다. 적용은 모든 창에 적용 중 카드와 입력 보호를 띄운다.
- 자동 저장 복구 제안은 첫 창에서만, 창 크기·위치 기억도 첫 창만, 새 창은 가장 최근 창에서 비스듬히 빈 자리에.

비범위: 탭 UI, 창 사이 문서 이동, 창 배치 복원(다음 실행에 창 여러 개 다시 열기), 설정의 창 간 실시간 동기화,
macOS Dock 종료·로그아웃·Windows 로그오프의 저장 확인(OS 종료 경로), 엔진·웹 빌드 변경.
