# HanPage Desktop 변경 이력

## 미출시

- 업데이트를 다 받으면 화면 오른쪽 아래에 "새 버전 준비됨" 작은 알림을 한 번 띄웁니다. 편집 중인 화면을 가리거나 커서를 옮기지 않고 8초 뒤 닫히며, `업데이트`로 바로 적용하거나 `나중에`로 닫을 수 있습니다.

## 0.8.10 — 2026-10-08

- Windows에서 앱이 꺼져 있을 때 한글 파일을 더블클릭하거나 `연결 프로그램`으로 열면 빈 문서만 뜨던 문제를 고쳤습니다.
- 이미 실행 중인 앱에 다른 폴더의 상대 경로로 넘긴 파일도 올바른 위치에서 엽니다.
- 파일 연결이나 최근 문서로 넘어온 파일을 읽지 못하면 아무 반응 없이 넘어가지 않고 이유를 안내합니다.
- macOS 설치 파일의 서명·공증을 배포 전에 자동으로 확인합니다. Windows 설치 파일은 코드 서명 없이 배포하며, 설치 시 "Windows의 PC 보호" 화면이 뜨면 `추가 정보 → 실행`을 누르면 됩니다.

## 0.8.9 — 2026-10-02

- 백그라운드 업데이트는 하단 상태 버튼에 표시하며, 상세 안내는 버튼과 업데이트 확인 메뉴에서 다시 열 수 있습니다.
- 업데이트 팝업을 화면 가운데에 배치하고 앱 테마와 어울리는 별도 색상으로 구분합니다.
- 최신 버전 안내는 `닫기`와 `다시 확인`을 제공합니다.
- 제품 정보와 설치 프로그램의 회사 표기를 `PALDYN`으로 통일합니다.

## 0.8.8 — 2026-10-02

- 업데이트 알림을 앱 테마에 맞는 카드로 정리하고 버튼을 `업데이트`로 표시합니다.
- 다운로드 용량·진행률과 파일 확인·적용 중 상태를 보여줍니다.
- 나중에 닫은 알림은 하단 업데이트 버튼과 macOS 메뉴에서 다시 열 수 있습니다.
- 저장 확인과 적용 중 입력 보호, 실패 후 받은 파일 재시도를 제공합니다.
- 안내 문장은 문장 끝에서 줄을 나누어 표시합니다.

## 0.8.7 — 2026-10-02

- 0.8.6 후보의 새 한글 심볼 로고와 upstream 0.8.6 통합 기능을 포함합니다.
- macOS·Windows 배포 빌드 도구 버전을 고정하고 Windows 네이티브 빌드 경로를 사용합니다.
- 자동 업데이트 서명과 macOS 서명·공증을 검증한 설치 파일로 배포합니다.

## 0.8.6 후보 — 2026-10-02 (미공개)

- HWP/HWPX 엔진과 편집기를 upstream 0.8.6으로 통합했습니다.
- 앱·Dock·Windows 실행 파일과 설치 프로그램에 새 한글 심볼 로고를 적용했습니다.
- 네이티브 파일 열기·저장, 연속 파일 열기 큐, 최근 문서·제목, 자동 업데이트 기능을 보존했습니다.
- 폰트 로딩의 개별 5초·초기 화면 8초 제한과 남은 폰트의 백그라운드 로딩을 유지했습니다.
- 작은 화면에서 웹 메뉴의 앱 다운로드 버튼이 넘치는 문제를 조정했습니다.

배포 대상은 macOS Apple Silicon과 Windows x64입니다. 앱은 새 버전을 백그라운드에서 내려받고, 준비되면 하단 상태 버튼에 표시하며 상세 안내를 다시 열 수 있습니다. macOS는 설치 후 재시작하고 Windows는 설치 프로그램을 실행합니다.
