# HanPage Desktop 변경 이력

## 0.8.7 — 2026-10-02

- 0.8.6 후보의 새 한글 심볼 로고와 upstream 0.8.6 통합 기능을 포함합니다.
- macOS·Windows 배포 빌드 도구 버전을 고정하고 Windows 네이티브 빌드 경로를 사용합니다.
- 자동 업데이트 서명과 macOS 서명·공증을 검증한 설치 파일로 배포합니다.

## 0.8.6 후보 — 2026-10-02 (미공개)

- HWP/HWPX 엔진과 편집기를 upstream 0.8.6으로 통합했습니다.
- 앱·Dock·Windows 실행 파일과 설치 프로그램에 새 한글 심볼 로고를 적용했습니다.
- 네이티브 파일 열기·저장, 연속 파일 열기 큐, 최근 문서·제목, 자동 업데이트 기능을 보존했습니다.
- 폰트 로딩의 개별 5초·초기 화면 8초 제한과 남은 폰트의 백그라운드 로딩을 유지했습니다.
- 작은 화면에서 웹 메뉴의 앱 다운로드 버튼이 넘치는 문제를 조정했습니다.

배포 대상은 macOS Apple Silicon과 Windows x64입니다. 앱은 새 버전을 백그라운드에서 내려받고, 준비되면 설치 안내를 표시합니다. macOS는 설치 후 재시작하고 Windows는 설치 프로그램을 실행합니다.
